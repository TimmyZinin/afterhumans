## Инциденты спринта (честный лог)
1. Пыль-квады: URP Particles/Unlit без спрайта рендерил жёсткие жёлтые квадраты. Фикс-1 (transparent-сетап из кода) не влился, фикс-2 (Sprites/Default + мягкий спрайт) в WebGL тоже давал квады (текстура терялась в билде). Фикс-3 — геометрический (v3.1): эмиттер поднят (низ бокса 3.2м при камере ~1.4м, ближняя видимая частица ≥3.5м), размер 0.008-0.02м → на экране ≤4px, квадратность физически не читается. Подтверждено `c6_spawn.png`. Подход менялся каждый раунд (IL-3).
2. WATCH OUT: декал создан давним ComposeRealAssets и живёт в сохранённой сцене; правка того кода ничего не меняла (мёртвый для пайплайна код). Фикс перенесён в DressSetToReference (живой прогон): yaw 180→0 (Quad виден с юга), z=-0.95, y 2.0→1.55 (в поле зрения камеры). Лог `watchOutFlipped=True`.
3. Ложный регресс ambient=0: гонка верификатора (патч счётчика после загрузки Unity). Фикс в скрипте, билд звук не терял.
