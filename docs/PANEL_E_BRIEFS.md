## J3 — Играбельность

Критерии:
1. W = вперёд, S = назад (живая проверка, приказ Тима после двух инверсий) (блокер при нарушении).
2. Управление отзывчиво, камера за спиной, без клипа в геометрию (≥8).
3. Полный проход: сцена 1 → все NPC → дверь → fade-переход → сцена 2 → подход к Анне → диалог по E → задел сцены 3 (≥8).
4. Ни одного зависания/чёрного экрана/потери управления; консоль браузера без красных ошибок (≥8).
5. FPS субъективно играбелен на WebGL (нет слайдшоу) (≥7).
6. Тач-контролы присутствуют (мобильный оверлей D17 не потерян) (≥8).
