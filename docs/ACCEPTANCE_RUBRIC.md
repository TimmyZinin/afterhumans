# Рубрика приёмки — фабрика Afterhumans (июль 2026)

Единый документ порогов для судейских панелей. Каждый спринт принимает панель из 3 НЕЗАВИСИМЫХ судей
(свежий контекст, без автора). Вердикт судьи: балл 1-10 по каждому пункту своей секции + общий
ACCEPT/REJECT + конкретные findings. Спринт закрыт, когда медиана панели ≥8 по каждому пункту секции
и нет ни одного findings-BLOCKER. REJECT → findings становятся задачами следующего раунда.
После 3 REJECT подряд — обязательная смена подхода (не повтор).

Судьи НЕ слышат аудио — звук принимается ТОЛЬКО по метрикам (reverse-STT, LUFS/dBTP, счётчики
AudioBufferSourceNode.start) и скриншотам субтитров. Судьи видят: скриншоты, транскрипты, телеметрию,
логи верификаторов, этот документ.

## Спринт D — живые NPC (роль в сюжете = движение)

Судьи оценивают ТОЛЬКО по живому WebGL-билду (скрин-серии/пиксель-дифф/видео-кадры). Порог пункта ≥8/10. Речи NPC не менялись — контент диалогов не судится.

| # | Пункт | Порог/доказательство |
|---|---|---|
| D1 | Ни один NPC не висит в воздухе и не «ездит» по полу без ног | Скрины каждого NPC: контакт с опорой (диван/стул/пол); нет скольжения корпуса без анимации конечностей (серия кадров при перемещении, если NPC ходит) |
| D2 | Каждый из 5 NPC имеет ЗАМЕТНУЮ скелетную/суставную анимацию | Серия кадров ≥4 с видимым изменением позы конечностей (не микро-боб всего объекта); пиксель-дифф зоны NPC ≥3% на паре кадров 2с |
| D3 | Анимация соответствует роли в сюжете | Саша — сидит/полулежит на диване живо; Кирилл — у плиты РЕАЛЬНО мешает/жестикулирует над кастрюлей; Мила — за терминалами (чтение/печать/поворот головы); Стас — возится у сервера/стеллажа; Николай — живая стойка у своего места. По кадрам роль читается без подписи |
| D4 | Органичность: масштаб, позиция, ориентация NPC вписаны в пространство | Нет проваливания в мебель, нет отрыва >5см от опоры, лица/корпус ориентированы осмысленно (к собеседнику/рабочему месту) |
| D5 | Регресс: A/B/C не сломаны | verify-скрипт зелёный (load/ambient/walk/E/console), собака и звук живы, декор на месте (спавн-скрин сравнить с c7_spawn.png) |

REJECT любого пункта → findings с конкретикой → новый раунд производства. 3 REJECT подряд по одному пункту → смена подхода (другой инструмент из разрешённых: Tripo / Blender / процедурный аниматор).
