## ⚠️ Модели в аккаунте — HD (1–2M полигонов), НЕ game-ready

SUV = **1 925 546 faces / 1 024 578 vertices**. Это киношное качество. Для мобильной игры (M1 8GB) любой ассет из библиотеки перед Unity ОБЯЗАН пройти **Retopo** (в Tripo, вкладка Retopo) или децимацию в Blender. Учитывать в бюджете трудозатрат.

## Оценка «что перегенерить/анимировать и почём» (для оркестратора)

Приоритет оркестратора: анимация сидящих NPC (person/npc_reading) → меш собаки → пропсы.

1. **Анимация NPC `person.glb` / `npc_reading.glb` — БЕЗ новой генерации.** В риг-туле есть **«Upload 3D Model» (OBJ/FBX/STL/GLB ≤150MB)** → грузим наши локальные NPC → **Auto Rig 20 кр** → применяем анимацию-пресет (idle/sit) → **Export**. **≈20 кр/модель**, 2 NPC ≈ **40 кр**. Самый дешёвый и прямой путь под задачу C (анимация NPC).
   - ⚠️ Оговорка: авто-риг Tripo рассчитан на гуманоида/квадрупеда в **A/T-позе**. `npc_reading.glb` уже в сидячей позе — авто-риг может лечь криво. Плюс нужна именно поза «сидит/читает/печатает» — проверить, есть ли такой пресет в библиотеке анимаций (я видел afraid/agree/angry; sit/idle/typing не подтвердил). Если точного пресета нет — путь не сработает, тогда риг+анимация в Blender/Mixamo.
2. **Меш собаки.** Корги уже локально (`kafka_corgi.*`, `kafka_tripo/kafka_animated.fbx` 42MB) и в аккаунте (ID `09367886…`). Улучшение: **Retopo** существующей (game-ready топология вместо ручной децимации) или Retexture. Новая HD-ген = 55 кр, если нужна другая база. Дешевле и без трат — почистить локальный FBX в Blender.
3. **Пропсы Botanika.** Библиотечные (диван-честерфилд, камин) стилистически не в тему ретро-кафе. Под Art Bible генерить новые: **55 кр/шт**. Бюджета хватает на ~50 пропов, но нужны точные промпты под «impressionist painterly warm».

**Мой вывод оркестратору:** самый оправданный расход прямо сейчас — попытка анимации 2 NPC через Upload→Auto Rig (~40 кр, копейки от 3200), НО сначала проверить наличие sit/idle-пресета и качество авто-рига на сидячей модели. Если авто-риг сидячего NPC ложится плохо — не жечь кредиты, идти через Blender/Mixamo. Массовая перегенерация библиотеки не нужна: под Afterhumans релевантны единицы моделей.

## Почему API не отдал список (проверено)

- `/user/balance` → 200 (работает).
- `/task`, `/tasks`, `/user/tasks`, `/task/list`, `/history`, `/workspace/tasks`, `?page=` / `?offset=` — все **405/404/400**. Публичного list-эндпоинта в API v2 нет.
- `GET /task/{id}` работает (fake id → `code:2001 not found`), но **сохранённых task_id в проекте нет** (в git/логах/скриптах id генераций не сохранялись — печатались только в stdout).
- Studio использует внутренний `api.tripo3d.ai/v2/studio/assets/v2?asset_type=mine&type=all` — доступен только из залогиненной веб-сессии, не по нашему API-ключу.

## Статус скачивания (честно)

**Автоскачивания GLB в `Assets/_Project/Models/TripoLibrary/` НЕ сделано.** Причины:
1. Прямые URL моделей (подписанные, с query-строкой) заблокированы защитным фильтром браузер-сессии при программном извлечении — обходить фильтр нельзя.
2. На плитке грида и в публичной карточке модели кнопки «скачать» нет (только «избранное»/«удалить»/«Create Now»). **НО путь скачивания найден (раунд 2):** открыть модель в **3D Workspace → редактор → кнопка «Export» внизу справа** (выгружает FBX/GLB). Стоимость экспорта не подтверждена (рядом бейдж «+300», не жал), но это штатный способ выгрузки owned-моделей.

## Рекомендации к использованию

**NPC-анимации:** rigged только корги (A1, уже локально) и кот (A2). Люди A3/A4 — статичные меши (риг перепроверить). Для анимированных NPC-людей в Afterhumans опираться на существующие локальные (`person.glb`, `npc_reading.glb`) + процедурные аниматоры, а не на Tripo-библиотеку.

**Пропы сцены (Botanika):** реально в тему только зелёный диван-честерфилд (A5) и, возможно, камин (A6). Остальное (глэмпинг, брендинг, фэнтези, анатомия) — из чужих проектов, не подходит по стилю ретро-кафе.

**Собака:** hero-корги (A1) уже интегрирован локально (`kafka_corgi.fbx` + `kafka_tripo/kafka_animated.fbx` 42MB оригинал). Из Tripo дополнительно тянуть нечего — за исключением возможности вытащить более чистую версию корги по ID `09367886-…` если текущая локальная не устраивает.

**Итог:** библиотека доступна и большая, но под Afterhumans релевантны буквально 2–4 модели (кот + опц. диван/камин/люди); ключевой ассет (корги) уже локально. Массовая ценность библиотеки — для проектов глэмпинга и Zinin×Shturbin, не для игры.
